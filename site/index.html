本站如何處理資料

本站為靜態網站，沒有帳號、交易或金鑰提交表單，不部署本站分析追蹤工具。瀏覽器的 localStorage 僅儲存外部資料同意狀態、選定標的、K 線週期、時區與新聞範圍；這些設定不傳給本站後端。選定標的會在你允許載入時傳給 TradingView。

GitHub Pages 託管服務會為安全用途記錄訪客 IP；此外，點擊外部連結後，該網站的隱私政策適用。
